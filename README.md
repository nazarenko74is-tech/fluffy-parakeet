# SEGA MASTER — Demo V1

Первая рабочая Android-демо: интерактивный 2D-персонаж поверх других приложений.

## Demo V1
- overlay поверх экрана;
- перетаскивание пальцем;
- реакция на короткое нажатие;
- idle-анимация;
- автоматическое перемещение;
- foreground service;
- Start/Stop;
- Android 13+ notification permission;
- Android 14+ `specialUse` foreground-service type.

## Сборка
GitHub Actions workflow находится в `.github/workflows/build-apk.yml` и собирает `app-debug.apk`.

## Установка
Открой приложение, выдай разрешение «Отображение поверх других приложений» и нажми «ЗАПУСТИТЬ SEGA MASTER».
